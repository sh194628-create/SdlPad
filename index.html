DirectX11 × SDL3 入力ガイド

はじめて使う人のための SdlPad 取扱説明書

DirectX11 の自作ゲームで、Xbox / PS4・PS5 / Nintendo Switch（プロコン・Joy-Con・Switch 2 プロコン）のコントローラーを同じ書き方で使えるようにする仕組みです。描画は DirectX11 のまま、入力の読み取りだけを SDL3 に任せています。

対応：Xbox / PS / Switch 開発環境：VS2022 / C++ / x64 SDL3 3.4.20 (VC) zlib ライセンス（商用・配布OK）

1最短スタート（まずはここから）

初期化や毎フレーム更新はもう終わっています！

Learn3dDirectX.cpp と Core/engine.cpp に初期設定が組み込み済みです。自分のシーンやプレイヤー処理でコントローラーを使いたいときは、下の2ステップだけで動きます。

1ヘッダーを読み込む

使いたい .cpp ファイルの先頭に #include "System/SdlPad.h" を1行足します。

2SdlPad:: で入力を読む

SdlPad::Trigger(...) や SdlPad::Axis(...) を書くだけで、どのメーカーのパッドでも反応します。

最小のサンプル（ジャンプと移動） 
#include "System/SdlPad.h"     // ← これを入れるだけ
#include "System/keyboard.h"   // キーボードも併用する場合

void Player::Update()
{
    // 下ボタン（Xbox:A / PS:× / Switch:B）か スペースキーを押した瞬間にジャンプ
    if (SdlPad::Trigger(SDL_GAMEPAD_BUTTON_SOUTH) || Keyboard_IsKeyTrigger(KK_SPACE))
    {
        Jump();
    }

    // 左スティックで移動（Xは右がプラス、Yは上をプラスにするためマイナスを付ける）
    float moveX = SdlPad::Axis(SDL_GAMEPAD_AXIS_LEFTX);
    float moveY = -SdlPad::Axis(SDL_GAMEPAD_AXIS_LEFTY);
}

※ コントローラーが1台もつながっていない状態でもエラーにはならず、ボタンは常に false、スティックは 0.0f を安全に返します。同時対応は1台で、遊んでいる最中に抜き差ししても自動で再認識・切り替えされます。

2ボタン判定 3種類の使い分け

ボタンを読み取る関数は Press / Trigger / Release の3種類あります。やりたいアクションに合わせて選んでください。

Trigger(ボタン)

押した瞬間（1フレームだけ）反応します。
用途：ジャンプ、決定、攻撃開始、ポーズ切り替え

Press(ボタン)

押している間ずっと反応します。
用途：ダッシュ、ガード、連射、十字キー移動

Release(ボタン)

離した瞬間（1フレームだけ）反応します。
用途：溜め攻撃を放つ、長押しキャンセル

フレームごとの反応イメージ

関数 1F：押していない 2F：押した！ 3F：押しっぱなし 4F：押しっぱなし 5F：離した！ 6F：押していない
SdlPad::Trigger(...) false true false false false false
SdlPad::Press(...) false true true true false false
SdlPad::Release(...) false false false false true false

3ボタン・軸マップ（クリックで定数名を確認）

SDL3 では、ボタンに書いてある文字（A/B や ○/×）ではなく物理的な位置（上・下・左・右）で名前が決まっています。たとえば「下にあるボタン」は Xbox・PS・Switch のどれを繋いでも SDL_GAMEPAD_BUTTON_SOUTH です。

図のボタンやスティックをクリックすると下にコードが出ます
下ボタン（Xbox: A / PS: × / Switch: B）
SdlPad::Trigger(SDL_GAMEPAD_BUTTON_SOUTH)
ジャンプや決定などによく使われる右側・下のボタンです。

スティックの向き（Y軸だけ上下に注意！）

1. デッドゾーンは自動処理済み：真ん中のオレンジ円（倒し具合 20% 未満）は自動で 0.0f になるため、スティックの微ブレ対策は不要です。20%～100% の範囲は滑らかに 0.0f ～ 1.0f へ引き伸ばされます。

2. 上方向をプラスにしたいときはマイナスを付ける：SDL3 の仕様上、スティックを下に倒すとプラスになります。3Dゲームの「前進＝プラス」や 2Dの「上＝プラス」にしたい場合は -SdlPad::Axis(SDL_GAMEPAD_AXIS_LEFTY) と書きます。

4やりたいこと逆引きレシピ（コピペOK）

実際のゲーム作りでよく使うパターンをそのままコピーできるようにまとめました。

基本 キーボードとコントローラーの両方でジャンプできるようにする

||（または）でつなぐだけで、コントローラー未接続のPCでもキーボードで遊べます。

C++
if (SdlPad::Trigger(SDL_GAMEPAD_BUTTON_SOUTH) || Keyboard_IsKeyTrigger(KK_SPACE))
{
    Jump();
}
移動 左スティックと WASD キーの両方で移動する

スティック値にキーボード入力を足し合わせます（斜め移動が速くならないよう、必要なら長さを1に丸めてください）。

C++
float moveX = SdlPad::Axis(SDL_GAMEPAD_AXIS_LEFTX);
float moveZ = -SdlPad::Axis(SDL_GAMEPAD_AXIS_LEFTY); // 前進をプラスにするため反転

if (Keyboard_IsKeyDown(KK_D)) moveX += 1.0f;
if (Keyboard_IsKeyDown(KK_A)) moveX -= 1.0f;
if (Keyboard_IsKeyDown(KK_W)) moveZ += 1.0f;
if (Keyboard_IsKeyDown(KK_S)) moveZ -= 1.0f;
トリガー LT / RT（L2 / R2 / ZL / ZR）をボタン代わりに使う

トリガーはボタンではなく「押し込み量（0.0f ～ 1.0f）」の軸として返ります。半分以上押し込んだら発動する例です。

C++
float rt = SdlPad::Axis(SDL_GAMEPAD_AXIS_RIGHT_TRIGGER);
if (rt > 0.5f)
{
    FireWeapon();
}
演出 ダメージを受けたときにコントローラーを振動させる

Rumble(重い振動 0～1, 軽い振動 0～1, 時間ミリ秒) を呼びます。振動を途中で止めたいときは Rumble(0, 0, 0) です。

C++
// 強めの振動を 0.25秒（250ms）鳴らす
SdlPad::Rumble(0.8f, 0.3f, 250);
UI表示 つながっている機種（PS / Switch / Xbox）を調べる

画面に「×ボタンで決定」「Aボタンで決定」などのガイドを出し分けたいときに使います。

C++
if (SdlPad::IsConnected())
{
    switch (SdlPad::Type())
    {
    case SDL_GAMEPAD_TYPE_PS4:
    case SDL_GAMEPAD_TYPE_PS5:
        // PlayStation 用のアイコンを表示
        break;
    case SDL_GAMEPAD_TYPE_NINTENDO_SWITCH_PRO:
    case SDL_GAMEPAD_TYPE_NINTENDO_SWITCH_JOYCON_PAIR:
        // Switch 用のアイコンを表示
        break;
    default:
        // Xbox 用のアイコンを表示
        break;
    }
}

5絶対に守るルール・よくあるミス

ルール1：SdlPad::Update() は自分で呼ばない！

SdlPad::Update() はすでに Core/engine.cpp の 60FPS ループ内で1回だけ呼ばれています。自分のシーンやクラスでもう一度呼んでしまうと、「前のフレームの記憶」が上書きされて Trigger() と Release() が一切反応しなくなります。

ルール2：テスト前に裏のコントローラー変換ソフトを終了する

DS4Windows / BetterJoy / x360ce / Steam（Steam Input）が起動していると、SDL3 と入力がぶつかってボタンが2回押されたり反応しなくなったりします。動作テストの前はこれらを閉じてください。

Switch 2 プロコンの接続方法

Switch 2 Proコントローラーを使う場合は、無線ではなく USB 有線接続 にしてください。

初期化・終了の呼び出し場所

Init() は Learn3dDirectX.cpp の DirectX 初期化後、Shutdown() はメインループ終了後に配置済みなので動かさないでください。

すべて static メソッドなので、変数を作らずそのまま SdlPad::〜 と書きます。

Directory.Build.targets について

Visual Studio のプロパティ画面に毎回手入力しなくても済むように、ソリューション直下の Directory.Build.targets に設定をまとめています（.props だと .vcxproj 側に上書きされるため .targets を採用しています）。

  • SDL3\include と /utf-8 オプションをコンパイラへ自動追加
  • SDL3\lib\x64 と SDL3.lib をリンカーへ自動追加
  • ビルド前に SDL.h が存在するかチェックし、無ければ警告を表示
  • ビルド後に SDL3.dll を実行フォルダーへ自動コピー（変更がない場合はスキップし、xcopy による VS フリーズを回避）

8困ったときの対処法（トラブルシューティング）

Q. ビルド時に「C1083: include ファイルを開けません。'SDL3/SDL.h'」が出る
  1. 出力ウィンドウに [SDL3] SDL.h not found: ... の警告が出ていないか確認します。出ていれば、MyGame\SDL3\include\SDL3\SDL.h の階層がずれています。
  2. プロジェクトのプロパティ → C/C++ → 全般 → 追加のインクルードディレクトリ → プルダウンの「編集」を開き、下部の「評価された値」に ...\SDL3\include が入っているか確認します。
  3. 入っていなければ、Directory.Build.targets が MyGame.sln と同じ場所にあるか、ファイル名に .txt が付いていないか確認します。
  4. すぐ動く状態に戻したい場合は、Directory.Build.targets の名前を Directory.Build.targets.bak などに変えて無効化し、下の「手入力設定への復旧表」をプロパティへ入力してください。
プロパティの場所（すべての構成 / x64・既存値の先頭に追加） 設定する値
C/C++ → 全般 → 追加のインクルードディレクトリ$(SolutionDir)SDL3\include;
C/C++ → コマンドライン → 追加のオプション/utf-8
リンカー → 全般 → 追加のライブラリディレクトリ$(SolutionDir)SDL3\lib\x64;
リンカー → 入力 → 追加の依存ファイルSDL3.lib;
ビルドイベント → ビルド後のイベント → コマンドラインcopy /y "$(SolutionDir)SDL3\lib\x64\SDL3.dll" "$(OutDir)SDL3.dll"
Q. 起動時に「SDL3.dll が見つからない」と表示される

SDL3\lib\x64\SDL3.dll を、ビルドされた .exe と同じフォルダーにコピーしてください。通常は Directory.Build.targets のビルド後処理で自動コピーされます。

Q. コントローラーが反応しない・ボタンが二重に反応する
  1. DS4Windows / BetterJoy / x360ce / Steam（Steam Input）をすべて終了してからゲームを再起動してください。
  2. Switch 2 Proコントローラーを使っている場合は、USB ケーブルで有線接続してください。
  3. Trigger() だけ効かない場合は、Core/engine.cpp 以外で SdlPad::Update() を呼んでいないか検索してください。

System/SdlPad.h
MyGame\System\SdlPad.h
#pragma once
#include <SDL3/SDL.h>

// SDL3を入力専用で使うゲームパッドクラス（描画はDirectXのまま）
class SdlPad {
public:
    static bool Init();
    static void Shutdown();
    static void Update();   // 毎フレーム1回呼ぶ
    static bool IsConnected() { return s_pad != nullptr; }
    static bool Press(SDL_GamepadButton b)   { return Valid(b) && s_now[b]; }                // 押している間
    static bool Trigger(SDL_GamepadButton b) { return Valid(b) && s_now[b] && !s_prev[b]; }  // 押した瞬間
    static bool Release(SDL_GamepadButton b) { return Valid(b) && !s_now[b] && s_prev[b]; }  // 離した瞬間
    static float Axis(SDL_GamepadAxis a);    // スティック -1～1 / トリガー 0～1
    static void Rumble(float low, float high, Uint32 ms); // 強さ 0～1
    static SDL_GamepadType Type();           // 機種の判定
private:
    static bool Valid(SDL_GamepadButton b) { return b >= 0 && b < SDL_GAMEPAD_BUTTON_COUNT; }
    static void OpenFirst();
    static SDL_Gamepad* s_pad;
    static bool s_now[SDL_GAMEPAD_BUTTON_COUNT];
    static bool s_prev[SDL_GAMEPAD_BUTTON_COUNT];
};
System/SdlPad.cpp
MyGame\System\SdlPad.cpp
#include "SdlPad.h"
#include <cstring>

SDL_Gamepad* SdlPad::s_pad = nullptr;
bool SdlPad::s_now[SDL_GAMEPAD_BUTTON_COUNT] = {};
bool SdlPad::s_prev[SDL_GAMEPAD_BUTTON_COUNT] = {};
static const float kDeadZone = 0.2f;

bool SdlPad::Init() {
    SDL_SetHint(SDL_HINT_JOYSTICK_THREAD, "1");                  // Win32ウィンドウで使うため
    SDL_SetHint(SDL_HINT_JOYSTICK_ALLOW_BACKGROUND_EVENTS, "1");
    if (!SDL_Init(SDL_INIT_GAMEPAD)) {
        SDL_Log("SDL_Init failed: %s", SDL_GetError());
        return false;
    }
    OpenFirst();
    return true;
}

void SdlPad::Shutdown() {
    if (s_pad) { SDL_CloseGamepad(s_pad); s_pad = nullptr; }
    SDL_Quit();
}

// 接続中のパッドのうち最初の1台を開く
void SdlPad::OpenFirst() {
    int count = 0;
    SDL_JoystickID* ids = SDL_GetGamepads(&count);
    if (ids) {
        if (count > 0) s_pad = SDL_OpenGamepad(ids[0]);
        SDL_free(ids);
    }
}

void SdlPad::Update() {
    SDL_Event e;
    while (SDL_PollEvent(&e)) {
        if (e.type == SDL_EVENT_GAMEPAD_ADDED && !s_pad) {
            s_pad = SDL_OpenGamepad(e.gdevice.which);
        } else if (e.type == SDL_EVENT_GAMEPAD_REMOVED && s_pad &&
                   SDL_GetGamepadID(s_pad) == e.gdevice.which) {
            SDL_CloseGamepad(s_pad);
            s_pad = nullptr;
            OpenFirst();   // ほかにつながっていれば切り替え
        }
    }
    std::memcpy(s_prev, s_now, sizeof(s_now));
    for (int i = 0; i < SDL_GAMEPAD_BUTTON_COUNT; ++i)
        s_now[i] = s_pad && SDL_GetGamepadButton(s_pad, (SDL_GamepadButton)i);
}

float SdlPad::Axis(SDL_GamepadAxis a) {
    if (!s_pad) return 0.0f;
    float v = SDL_GetGamepadAxis(s_pad, a) / 32767.0f;
    v = SDL_clamp(v, -1.0f, 1.0f);
    float mag = SDL_fabsf(v);
    if (mag < kDeadZone) return 0.0f;
    float out = (mag - kDeadZone) / (1.0f - kDeadZone);  // デッドゾーン外を0～1に詰め直す
    return v < 0.0f ? -out : out;
}

void SdlPad::Rumble(float low, float high, Uint32 ms) {
    if (!s_pad) return;
    low  = SDL_clamp(low,  0.0f, 1.0f);
    high = SDL_clamp(high, 0.0f, 1.0f);
    SDL_RumbleGamepad(s_pad, (Uint16)(low * 0xFFFF), (Uint16)(high * 0xFFFF), ms);
}

SDL_GamepadType SdlPad::Type() {
    return s_pad ? SDL_GetGamepadType(s_pad) : SDL_GAMEPAD_TYPE_UNKNOWN;
}

    engine.Init();
    int param = engine.Run();

    SdlPad::Shutdown();   // ループを抜けた後
    Cleanup();
    CoUninitialize();
    return param;
}

#include "System/SdlPad.h"

void Engine::Init() {
    Keyboard_Initialize();
}

int Engine::Run() {
    MSG msg = {};
    DWORD dwExecLastTime = timeGetTime();
    DWORD dwCurrentTime = 0;
    SceneManager::GetInstance().ChangeScene("Sample");
    while (msg.message != WM_QUIT)
    {
        if (PeekMessage(&msg, nullptr, 0, 0, PM_REMOVE))
        {
            TranslateMessage(&msg);
            DispatchMessage(&msg);
        }
        else
        {
            dwCurrentTime = timeGetTime();
            if ((dwCurrentTime - dwExecLastTime) >= (1000 / 60))
            {
                dwExecLastTime = dwCurrentTime;
                SdlPad::Update();   // 1フレームに1回、シーン更新の前（elseの先頭に置くとTriggerが効かなくなる）
                SceneManager::GetInstance().Update();
                Keyboard_Update();
                Render_Set();
                SceneManager::GetInstance().Render();
                Render_Present();
            }
        }
    }
    return static_cast<int>(msg.wParam);
}

10配布時の注意点・今後の拡張アイデア

ゲームを人に渡す・配布するとき

必ず .exe と同じフォルダーに SDL3.dll（SDL3\lib\x64\SDL3.dll）を一緒に入れてください。SDL3 は zlib ライセンスのため、同梱配布・商用利用ともに OK で、クレジット表記も任意です。

さらに機能を増やしたいときのヒント

  • ボタン表記の自動取得：SDL_GetGamepadButtonLabel() を使うと、繋いだコントローラーの印字（A/B や ×/○）を自動で判別できます。
  • ジャイロ・傾き操作：SDL_SetGamepadSensorEnabled() と SDL_GetGamepadSensorData() で対応できます。
  • PS コントローラーのライトバー：SDL_SetGamepadLED() で好きな色に光らせられます。
  • 2人以上の対戦・協力プレイ：s_pad やボタン配列を人数分の配列（例：4人分）に拡張して管理します。
